# Architecture Decision Records

This directory holds the small, numbered decision records that define how the annotation package pipeline is organized and evolved.

## Protocol

- One ADR per decision.
- Keep each ADR short and focused.
- Update ADRs before implementation when a decision affects build structure, package interfaces, or documentation.
- Prefer explicit contracts over implicit script behavior.
